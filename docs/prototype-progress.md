## 3. 人工验收与演示验证路径

1. **任务与参数校验**：
   - 顶部导航点击“快速载入演示场景” → 选择“1. 空白新建任务”。
   - 尝试创建任务，故意输入结束日期早于开始日期，观察系统弹出的精确日期校验拦截。
2. **材料与冲突裁决**：
   - 选择预置场景“2. 存在口径冲突 (120 vs 128)”。
   - 查看结构化事实清单，点击“裁决冲突”，对比科室甲120与科室乙128的原文位置，选择采信128并输入理由。
   - 切换到模拟RAG，测试“仅有生成答案(CLUE-01)”，观察线索状态及不自动生成假出处的行为。
   - 点击“确认本次事实清单”，生成锁定快照。
3. **文风与大纲规划**：
   - 进入阶段03，核对文风规则中的例句及2025年旧年份隔离；调整大纲章节建议字数并核验总字数偏差；点击“确认大纲”。
4. **正文起草与依据追溯**：
   - 进入阶段04，点击“重新生成候选稿”，观察正文中的重点任务自动采纳所裁决的128项。
   - 点击正文中的“16场、800人次”，右侧定位出处，并可在段落工具中体验“压缩精炼”与前后对比采纳。
5. **审阅协同与篇幅冲突**：
   - 顶部切换当前角色为“审阅乙”或“审阅丁”，进入阶段05，观察正文处于受限只读批注模式。
   - 主笔查看审阅乙（压缩到2000字）与审阅丁（增加详细案例）的冲突横幅，点击“协调裁决此冲突”完成闭环。
6. **核校演练与真实导出**：
   - 进入阶段06，点击“模拟注入800人错误”，观察核校引擎立刻报警并指出EVD-03台账为“800人次”。
   - 点击“一键纠正为800人次”，核校恢复绿色。
   - 点击“确认最终定稿”，锁定版本；点击“下载公文 Word (.docx) 文件”，验证真实本地生成的 .docx 文件。
