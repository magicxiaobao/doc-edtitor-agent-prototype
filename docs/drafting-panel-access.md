# 正文起草：折叠面板持续访问与长内容滚动

## 2026-10-20 视觉复验后的补修

#64 已合并至 main（201a225）。用户同步 AI Studio 后，云端 Chrome 在 1363×887 桌面 iframe 实测四种面板组合、44px 恢复入口、增高顶栏避让、修改要求/目标段落/微调/辅助标签保留均可用；768×1024 平板抽屉基本开关可用。Escape 关闭抽屉时 AI Studio 外层全屏也退出，未把多层 Escape 隔离计为通过。

发现两项待修：

1. 生成建议后，右侧外层可视高度约 753px，而内容约 1490px；内部正文区虽设置 overflow-y:auto，却未在 flex 布局中收缩，滚轮无法到达微调与采纳区。
2. 在约 1040 字长段落中部用普通鼠标展开辅助面板，段落顶部从 -51px 变为 173px，阅读位置偏移约 224px。文本框测量时先将可见高度改为 auto，会暂时缩短文档并扰动滚动位置。

本次补修将辅助面板根节点及正文区设为可收缩 flex 项，保留不可收缩的标签/折叠标题，仅正文区滚动；正文高度使用同宽、同样式的隐藏临时文本框测量，测量后立即移除，不临时缩短可见段落。工作区关闭浏览器自动滚动锚定，避免与现有手动段落位置恢复叠加。

新增回归验证长段落测量期间可见高度不变、宽度变化重新测量、删减内容仍可缩短，以及测量节点不残留；既有上下文与焦点回归仍保留。JSDOM 不模拟真实浏览器滚动锚定或 flex 排版，不能替代部署后复验。
