# 正文起草：折叠面板的持续访问

## 本次范围

按用户确认，桌面端折叠章节大纲或辅助面板后，在对应一侧保留 44px 窄入口，标明“大纲／辅助”，并吸顶在实际导航栏下方。四种展开组合使用三条明确的网格轨道，避免正文占满 12 列后将恢复入口挤至下一行。展开的面板继续吸顶；平板仍使用既有抽屉。

切换前记录当前可见段落的位置，正文宽度变化后先同步调整文本框高度，再补偿阅读位置；焦点移到同侧的新按钮且不主动滚动页面。保留选中段落、辅助标签、修改指令及待采纳微调内容。
