## 已确认缺陷及本 PR 修复

### P1：原生确认框阻断 AI Studio 定稿与重置

在步骤 6，定稿按钮可用、六项准入为绿色，点击后无对话框、无状态变化。预览 iframe 的 sandbox 未含 `allow-modals`；代码使用 `window.confirm`，与实测一致。重置数据使用相同调用。

本 PR 改为站内可取消确认框，包含焦点与 Escape 行为；定稿提交前按最新上下文重验准入，不放宽核校门禁。

### P2：将资料缺口说明误报为成效断言，并引用不存在的正文

步骤 4 实际填入“服务满意度相关量化材料尚待补齐，当前仅记录资料缺口，不据此作成效判断。”核校却显示当前正文为“服务满意度明显提升”。后者没有出现在该段。

本 PR 仅在命中受支持的正向满意度成效表述时提示，并展示实际命中的原句；常见缺口说明不再触发该误报。仍保留无核准依据的正向成效提醒，不承诺通用自然语言核校。

### P2：导航状态区被挤成竖排

步骤 1 截图右侧冲突提示逐字换行，使导航占用很高空间；后续更新时间也出现相同挤压。

本 PR 将状态信息放到独立行，保留阶段按钮的水平滚动与单行文字。

## 自动化与未验边界

本 PR 新增 `test-demo-journey.tsx`，在同一 App 中从冲突裁决、确认前序、生成与采纳候选、保存版本、人工编辑、实时新增审阅意见、落实、定稿直到重置。禁用原生 confirm，所有任务变更由实际组件操作产生；只读取持久化结果做断言，不直接修改任务状态来伪造闭环。另检查资料缺口不产生虚构引文，以及正向成效提示引用实际原句。

浏览器中没有绕过 iframe 限制或修改运行时代码。TXT/DOCX 下载等待没有返回完成路径，不能由此直接认定导出实现有缺陷，也不能报告下载成功。办公软件排版、移动端及全面无障碍合规均未验证。需要在合并并同步本 PR 后，重新验收线上定稿、重置、导航布局及实际下载。#40、#57 继续开放。
