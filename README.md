## 实施顺序

在AI Studio Build模式新建Web项目，粘贴任务文档中的共用提示词和任务01。依次完成01至06，每批验收后同步代码。本轮使用虚构资料和本地模拟服务；真实RAG与模型接口后续替换。

重点在任务02、任务04及任务06完成后评审。提交代码时更新docs/prototype-progress.md，记录批次、启动方法、验收路径、实测结果和待完成项。

代码与数据均提交到本仓库。保留现有docs，不上传真实单位材料、服务凭据或内网地址。仓库名称为doc-edtitor-agent-prototype，沿用现有拼写。
