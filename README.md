# 公文辅助协作原型系统 (doc-editor-agent-prototype)

面向机关单位公文主笔与审阅者，验证工作总结与汇报材料的台账整合、事实确认、文风约束、大纲规划、确定性起草、审阅协同与严谨核校定稿流程。

> **当前版本**：任务09实施完毕（本地确定性模拟原型）  
> **开发环境**：React 18 + TypeScript + Vite + Tailwind CSS  
> **服务边界声明**：当前系统为纯本地前端交互演示与确定性算法原型，尚未接入服务端权限控制、真实外网/LLM RAG、内网二进制文档解析及真实多人在线协作服务。

---

## 1. 快速启动与构建命令

```bash
# 1. 可复现依赖安装（使用 lockfile）
npm ci

# 2. 类型检查（tsc --noEmit）
npm run typecheck

# 3. 运行全量业务规则与有效验收测试（覆盖任务07、08、09全部验收点）
npm test

# 4. 生产打包构建（包含编译前类型检查）
npm run build

# 5. 启动本地开发服务（0.0.0.0:3000）
npm run dev
```

## 2. 核心功能实现状态与边界区分

| 模块 / 环节 | 关键业务能力 | 状态分类 | 实测与验证说明 |
| :--- | :--- | :--- | :--- |
| **事实比对与核校引擎** | 移除硬编码白名单，基于确认快照动态比对数值/单位/期间 | **已实测通过** | 自动化测试通过：采信128但正文写120精确定位阻断；同段“800人次，其中800人”准确检出单位混淆；过滤“1至/1至9月”避免误判。 |
| **核校闭环与阻断机制** | AuditIssue 类型完整绑定、接受修正改正文、阻断项禁止通用忽略 | **已实测通过** | 自动化测试通过：修正真实替换正文段落；阻断性重大冲突拦截通用忽略；非阻断警告记录理由随版本保存。 |
| **定稿准入把关** | 6项准入条件（正文、权限、前序审批、冲突解决、意见闭环、阻断清零） | **已实测通过** | 自动化测试通过：无正文、未裁决冲突、待处理意见或存在阻断偏差时严格拦截定稿。 |
| **真实文件导出 (TXT/DOCX)** | 支持相同正文/依据/审阅记录选择，导出指定冻结版本快照 | **已实测通过** | 自动化测试通过：TXT与DOCX均支持3项组合导出；历史导出锁定当时大纲标题；DOCX通过OOXML结构校验。 |
| **数据持久化与容灾** | SchemaVersion v2平滑迁移、损坏数据隔离备份、刷新不丢稿 | **已实测通过** | 自动化测试通过：旧版任务平滑升级；损坏JSON安全隔离并提供导出备份与重置恢复；超大内容自动精简防溢出。 |
| **交互与视觉标准** | UI至少14px、正文至少16px、1440/1280/1024响应式正文空间、演示专区隔离 | **已实现** | 界面文字全面达标；角色切换与演练工具归入演练专区；弹窗支持Esc关闭与可见焦点。 |
| **桌面Office/WPS实测** | 生成的DOCX在本地独立Word/WPS桌面客户端各版本的打开渲染效果 | **未验证** | 因沙箱环境无独立本地桌面Office客户端图形应用，端到端实际排版兼容性待进一步在目标桌面软件中实测验证。 |
| **本地图形截图录制** | 浏览器在多端物理视口下的实机高分辨率截屏与录屏 | **未验证** | 无本地无头图形显示服务，以自动化端到端测试与预览环境真实DOM交互为准。 |
| **真实生产环境后端** | 服务端RBAC权限鉴权、生产知识库RAG联调、真实多人WebSocket协同 | **待实现** | 当前明确属于原型交付范围之外的后续演进边界。 |
